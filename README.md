# Español — Fluency Lab
A mobile-first Spanish fluency app for heritage/intermediate-advanced speakers who understand Spanish but want stronger grammar and active production.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root (not inside another folder).
3. Commit the file.
4. Open Settings → Pages.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will display the published site URL after deployment.

Version 0.1 includes Grammar → Verb Tenses and a complete first lesson on the present indicative.
